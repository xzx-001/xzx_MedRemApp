MedRed 隐私政策

发布日期：2026年1月28日

应用名称：xzx吃药提醒助手

应用包名：com.companyname.medred

核心承诺：MedRed 为纯本地应用，所有数据均存储在您的设备本地，无需联网，不收集任何个人信息。

1. 数据处理原则

MedRed 是一款纯本地运行的服药提醒工具。您设置的所有提醒时间、药品名称、服用剂量、提醒设置等信息：

  • 仅保存在您的手机本地数据库中
  • 不会上传到任何服务器或云端
  • 不会通过互联网传输到任何地方
  • 不会与第三方共享任何数据
  • 卸载应用后数据将随应用一同删除

2. 权限使用说明

本应用仅申请以下必要的系统权限：

  • 前台服务权限 (FOREGROUND_SERVICE)：用于在后台持续运行提醒服务，确保准时提醒
  • 通知权限 (POST_NOTIFICATIONS)：用于在设定时间发送服药提醒通知
  • 精确闹钟权限 (SCHEDULE_EXACT_ALARM)：用于设置精确的提醒时间，确保准时提醒
  • 全屏意图权限 (USE_FULL_SCREEN_INTENT)：用于在锁屏界面显示全屏提醒
  • 振动权限 (VIBRATE)：用于在提醒时振动设备（可选）
  • 唤醒锁定权限 (WAKE_LOCK)：在提醒时保持设备唤醒，确保您能看到提醒
  • 开机启动权限 (RECEIVE_BOOT_COMPLETED)：用于在设备重启后自动恢复提醒服务
  • 前台服务数据同步权限 (FOREGROUND_SERVICE_DATA_SYNC)：用于前台服务的数据同步

我们不会申请以下敏感权限：

  • 网络访问权限
  • 位置权限
  • 通讯录权限
  • 相机权限
  • 麦克风权限
  • 外部存储权限

3. 数据存储与安全

所有数据均存储在设备的内部私有存储空间中：

  • 使用设备内置的 SQLite 数据库存储提醒设置
  • 使用设备本地文件系统存储应用配置
  • 所有数据均经过系统级加密保护
  • 其他应用无法访问本应用的私有数据

4. 第三方服务与 SDK

本应用集成了以下第三方库，这些库均运行在本地设备上：

  • CommunityToolkit.Maui：UI组件和工具
  • CommunityToolkit.Mvvm：MVVM开发框架
  • Plugin.LocalNotification：本地通知服务
  • Microsoft.Maui.Controls：跨平台UI框架

重要提示：本应用不包含任何广告SDK、分析SDK或第三方数据收集工具。

5. 应用功能与数据关联

本应用的功能与数据处理方式：

  • 语音播报功能：使用设备本地TTS引擎，无需网络连接
  • 震动提醒功能：直接调用设备震动马达，无需数据传输
  • 系统闹钟功能：使用Android系统AlarmManager API
  • 后台服务：使用Android前台服务确保提醒准时触发

6. 您的权利

  • 数据访问权：您可以在应用内随时查看所有存储的数据
  • 数据修改权：您可以随时修改或删除任何提醒设置
  • 数据删除权：卸载应用即可彻底删除所有本地数据
  • 使用自由：使用本应用无需注册账号或提供个人信息
  • 权限控制：您可以随时在系统设置中撤销应用权限

7. 儿童隐私保护

本应用不收集任何个人信息，包括儿童的任何信息。我们鼓励家长和监护人在儿童使用本应用时进行指导。

8. 隐私政策更新

我们可能会根据需要更新本隐私政策。如有重大变更，我们会在应用内提供显著通知。您继续使用本应用即表示接受更新后的政策。
