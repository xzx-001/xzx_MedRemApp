快速开始指南

首次使用xzx吃药提醒助手？按照以下步骤快速设置您的第一个服药提醒。

1
下载并安装应用

从应用商店下载并安装xzx吃药提醒助手应用。确保您使用的是最新版本以获取最佳体验。

注意：如果从第三方来源下载，请确保来源可信。

2
添加第一个服药提醒

打开应用后，点击主屏幕的"+"按钮添加新提醒。

填写药品名称、剂量、服药时间，并设置重复周期（每天、工作日、周末或自定义）。

3
设置提醒偏好

在设置页面，您可以自定义：

  • 语音播报音量
  • 振动模式
  • 提醒铃声
  • 重复提醒次数
4
启用后台权限

为确保提醒在后台正常工作，请按照后台权限设置指南配置您的手机设置。

这是确保提醒功能正常运行的关键步骤。

后台权限设置指南

为确保吃药提醒能在后台正常运行，请按照以下步骤设置应用权限。如果未正确设置，应用在屏幕关闭后可能无法正常提醒。

重要提示

大多数Android手机在默认设置下会限制后台应用活动以节省电量。为了确保xzx吃药提醒助手能在后台正常工作，您需要手动授予必要的权限。

华为/荣耀手机设置步骤

1
打开手机设置

进入手机的"设置"应用，找到"应用管理"或"应用权限"选项。

2
进入应用和服务

在设置中找到"应用和服务"选项并点击进入。

3
进入应用启动管理

点击"应用启动管理"选项。

4
搜索并找到xzx吃药提醒助手

在搜索框中输入"xzx"找到"xzx吃药提醒助手"应用。

5
关闭自动管理并手动设置

关闭"自动管理"，然后手动开启"允许自启动"和"允许后台活动"。

设置完成检查

完成上述步骤后，重启手机以确保设置生效。然后打开xzx吃药提醒助手，添加一个测试提醒以验证后台提醒功能是否正常工作。

常见问题解答

以下是用户经常遇到的问题和解决方案。

为什么手机锁屏后提醒不工作了？

这通常是由于手机系统为了省电而限制后台应用活动。您需要按照后台权限设置指南为xzx吃药提醒助手授予后台运行权限。

不同品牌的手机设置方法略有不同，请参考不同手机设置部分。

应用突然停止发送提醒怎么办？

请尝试以下解决方案：

  1. 检查手机是否开启了省电模式，省电模式可能会限制后台应用活动
  2. 确保应用的通知权限已开启
  3. 重启手机和应用
  4. 检查应用是否被手机系统"优化"或"强制停止"
如何备份我的服药记录？

当前版本中，所有数据都存储在您的设备本地以确保隐私安全。我们正在开发数据导出功能，将在后续版本中添加。

如果您需要备份数据，可以定期截图保存重要记录。

语音播报不工作怎么办？

语音播报问题可能由以下原因导致：

  • 手机媒体音量调至静音或过低
  • 应用内的语音音量设置过低
  • 手机系统TTS（文本转语音）引擎未正确安装
  • 应用没有语音播报权限

请检查以上设置，并尝试在应用设置中测试语音功能。

应用支持哪些语言？

当前版本主要支持中文。我们计划在未来版本中添加多语言支持。

如果您有特定语言需求，请通过联系支持告诉我们。

不同手机品牌设置方法

各品牌Android手机的后台权限设置位置和名称略有不同，以下是常见品牌的设置方法。

华为/荣耀

设置 → 应用 → 应用启动管理 → 关闭自动管理 → 允许后台活动

小米/红米

设置 → 应用设置 → 授权管理 → 自启动管理 → 允许自启动

OPPO/Realme

设置 → 应用管理 → 自启动管理 → 允许自启动

vivo/iQOO

设置 → 应用与权限 → 自启动 → 允许自启动

Google Pixel

设置 → 应用 → 特殊应用权限 → 电池优化 → 不允许优化

Samsung

设置 → 应用 → 电池 → 不受限制 → 允许后台活动

找不到设置选项？

如果您找不到上述设置选项，可以尝试在手机设置中搜索关键词："后台"、"自启动"、"电池优化"、"应用管理"等。不同手机系统版本可能有所差异。

故障排除

遇到问题？尝试以下方法解决常见故障。

提醒不工作的排查步骤

1
检查应用是否在后台运行

打开手机的多任务视图，确保xzx吃药提醒助手没有被清除。有些手机会自动清理后台应用以节省电量。

2
检查通知权限

进入手机设置 → 应用 → xzx吃药提醒助手 → 通知，确保通知权限已开启。

同时检查应用内部设置中的通知选项是否启用。

3
检查电池优化设置

大多数Android手机都有电池优化功能，可能会限制后台应用活动。请将xzx吃药提醒助手添加到电池优化白名单中。

设置路径通常为：设置 → 电池 → 电池优化 → 选择xzx吃药提醒助手 → 不允许优化。

4
重启应用和设备

有时简单的重启可以解决临时性问题。请彻底关闭应用并重新打开，或者重启您的手机。

5
检查系统闹钟权限

xzx吃药提醒助手使用系统闹钟功能来确保准时提醒。请确保应用有设置系统闹钟的权限。

在Android 12及更高版本中，这可能需要手动授予"精确闹钟"权限。

如果以上方法都无效

请尝试卸载并重新安装应用。在卸载前，请确保您已经记录了重要的服药提醒设置，因为重新安装会清除所有本地数据。

如果问题仍然存在，请通过联系支持向我们反馈问题。
